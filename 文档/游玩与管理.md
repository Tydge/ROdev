# 日常游玩与管理

## 一键启动

1. 双击 `自动化/启动RO.command`。
2. 等窗口显示数据库、登录服、角色服、地图服均为运行中。
3. Windows 11 恢复后，双击桌面的 `Local Classic RO`。

启动顺序由脚本自动处理：MariaDB → login-server → char-server → map-server → Windows 11。

## 一键关闭

1. 先在游戏里正常退出到 Windows 桌面。
2. 双击 `自动化/关闭RO.command`。
3. 脚本依次关闭地图服、角色服、登录服和本项目 MariaDB，然后暂停 Windows 11。

如果脚本检测到 `LocalRO.exe` 仍在运行，会要求确认，防止角色尚未退出时直接暂停。

Windows 使用“暂停”而非删除或重装。暂停后几乎不占用 CPU；下次运行启动脚本会自动恢复。

## 查看状态

双击 `自动化/查看RO状态.command`。正常游玩状态应为：

- MariaDB：运行中，端口 3307。
- login-server：运行中，端口 6900。
- char-server：运行中，端口 6121。
- map-server：运行中，端口 5121。
- Windows 11：running。

## 经验倍率

当前配置：

```text
base_exp_rate: 200
job_exp_rate: 200
quest_exp_rate: 200
castrate_dex_curve: 50
aspd_stat_curve: 80
item_rate_common: 200
item_rate_heal: 200
item_rate_use: 200
item_rate_equip: 200
item_rate_card: 3000
item_rate_mvp: 200
drops_by_luk2: 100
```

配置文件位于 `服务端运行目录/rathena/conf/import/battle_conf.txt`。

倍率 200 表示 2×。例如 Pre-Renewal 数据中波利原始 Job EXP 为 1；2× 后为 2。初心者 Job Lv.7 升级需求为 205，因此一只波利约为 `2 / 205 = 0.98%`，客户端显示约 1%，这正好与当前测试现象一致，说明 2× 已生效。

掉落规则：普通材料、恢复品、消耗品、装备和 Boss/MVP 非卡片奖励为 2×；普通、Boss、MVP 卡片统一为 30×。同时启用相对 LUK 加成：每点 LUK 增加当前掉率的 1%，理论上 50 LUK 为 1.5×、100 LUK 为 2×；极低概率物品会受 0.01% 最小精度取整影响。

## 任务在经典 RO 中的重要程度

经典 Pre-Renewal 前期的主循环主要是打怪升级、转职、刷装备和探索地图，不是现代 MMO 式的连续主线任务。转职、技能、区域剧情和部分装备任务仍然重要，但看不到大量推荐任务不会阻碍正常游玩。

## 当前战斗定制

- DEX 咏唱：`T = T0 × 50 / (50 + DEX)`。DEX 50 剩余 50%，DEX 100 剩余 33.3%，DEX 150 剩余 25%；DEX 本身不再产生零咏唱。
- Fire Ball：Lv1 100% MATK，每级增加 20%，Lv10 280% MATK。范围边缘目标仍承受中心伤害的 75%。
