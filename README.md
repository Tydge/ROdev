# RO 本地服（M1 Mac + Parallels + rAthena）

当前是可游玩的 Pre-Renewal 本地服。第一次接手请先看：

- `文档/AI接手说明.md`：完整架构、部署过程、配置、已解决问题和待办。
- `文档/游玩与管理.md`：日常启动、关闭、账号及倍率说明。
- `文档/Parallels试用到期说明.md`：准确到期日、购买后处理和版本选择。
- `自动化/启动RO.command`：双击启动数据库、三个服务端和 Windows 11 虚拟机。
- `自动化/关闭RO.command`：双击安全关闭服务端和数据库，并暂停虚拟机。
- `自动化/查看RO状态.command`：双击检查当前状态。

## 目录说明

- `服务端运行目录`：指向当前 rAthena、数据库、日志和安装资源的快捷入口。
- `开发工作目录`：指向客户端修复、Nemo、英文覆盖资源等工作文件。
- 真正的 Windows 客户端和虚拟机磁盘仍由 Parallels 管理，没有搬动。

## 版本管理

本目录使用 Git 管理文档、自动化脚本、角色规划与自研 OpenKore 插件。运行日志、数据库、账号配置、口令文件和大型归档由 `.gitignore` 排除；`服务端运行目录`、`开发工作目录` 等仍只是指向本机实际运行位置的符号链接。

不要删除 `服务端运行目录` 指向的目标，也不要直接修改角色数据库。操作前优先备份。
